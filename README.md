# Multi-Agent Article/Book Generation System

A toolchain for generating full-length (15-20 page) LaTeX books/articles using CrewAI.

## Requirements
- Python 3.12 (Due to binary dependency constraints on some libraries)
- MiKTeX

## Usage

```bash
C:\Users\lovel\AppData\Local\Programs\Python\Python312\python.exe main.py --topic "Your Topic Here" --language "English"
```
