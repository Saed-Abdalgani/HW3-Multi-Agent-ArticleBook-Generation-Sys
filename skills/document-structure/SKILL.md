# Document structure

- **Page budget:** aim **15–20 pages** total; allocate ~2–3 pages per chapter for a 6–7 chapter skeleton unless topic demands otherwise.
- Reserve **one chapter** explicitly for **BiDi** demonstration when Hebrew is involved.
- Outline must list **chapter purpose**, **target page band**, and **required assets** (figures/tables/equations) per chapter.
- Persist machine-readable outline as Markdown with `#` chapter headings.
